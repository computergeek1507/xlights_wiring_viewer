Privacy Policy — xLights Wiring Viewer

Last updated: 2026-08-22

xLights Wiring Viewer is a utility app for browsing the xLights vendor model catalog and viewing the physical pixel wiring order of xLights models. This page explains what the app does and does not do with your data.

No accounts, no personal data collection

The app has no login, no user accounts, and does not collect, store, or transmit any personal information. There is no analytics SDK, no advertising SDK, and no crash-reporting service embedded in the app.

Network requests

The app makes network requests only to fetch publicly available data you asked it to load:

  • The xLights vendor catalog (xlights_vendors.xml), hosted on GitHub.
  • A vendor's own model inventory and thumbnail images, hosted on that vendor's own website, when you open that vendor.
  • A .xmodel file, hosted on a vendor's website, when you tap "View Wiring" on one of their models.

These requests only ever send the request needed to fetch that public content (a standard HTTP GET) — the app does not attach any personal or device-identifying information to these requests beyond what any web request inherently includes (e.g. your IP address, visible to that server the same way it would be to any website you visit).

Local files you choose to open

"Load .xmodel from device" and "Load xlights_rgbeffects.xml" use the standard Android file picker. The chosen file is read and parsed entirely on your device to draw the wiring diagram — it is never uploaded anywhere.

On-device storage

The app caches the vendor catalog XML locally (via Android's standard app-preferences storage) so it still works if you're offline after the first load. This cache contains only that public vendor-list content — nothing about you. You can clear it at any time by clearing the app's storage in Android settings.

Third-party sites

Vendor websites and GitHub are operated by their own owners and have their own privacy practices, which this policy does not cover.

Changes to this policy

If this policy changes, the updated version will be posted at this same URL.

Contact

Questions about this app can be filed as an issue on the GitHub repository.
